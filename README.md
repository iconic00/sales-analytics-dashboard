Sales Analytics Dashboard is a web application built using FastAPI, PostgreSQL, and Chart.js to analyze sales data.
It provides insights such as:

📊 Daily sales trends

💰 Revenue analytics

📦 Product performance

🏆 Top-selling products

⚠️ Low inventory alerts

📈 Category-wise revenue visualization

The dashboard helps businesses monitor sales performance through interactive charts and APIs.
